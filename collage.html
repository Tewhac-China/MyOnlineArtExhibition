千禧迷思

Millennium Myth  ·  Procedural Collage

从一段 83 秒的参考动画里拆出层序，用 Python 重新搭一遍。六帧，没有一张用扩散模型， 没有任何像素是「生成」的 —— 环线、飞鸟、色块、贴纸框、每一个字的位置，都是代码算出来、画上去的。

01 / PIPELINE

生成方式

渲染内核是一个 Python 脚本（Pillow + NumPy），没有模型推理。参考片真正值得学的不是它的画面， 而是它的层序 —— 先立可读的形，再用照片供质感，强调色定量进场，文字最后落。

色轴是一条纪律。所有照片底、文字、飞鸟、弧线统一去色到 0–15% 饱和，明度压在 0.15–0.75； 紫罗兰只出现在色块、波纹填充与少量波形线上。这是「限制即风格」：把颜色配额几乎全押在一个强调色上， 画面立刻从「照片堆」变成「设计」。

8K 不是放大。整套管线参数化，几何、字号、线宽、模糊半径、网点步长全部乘一个系数 S。 三处会随解析度走形的东西必须一起修，否则高分辨率反而露馅：扫描线频率要固定在设计高度、颗粒要按设计尺寸生成 再平滑放大、小字要改成二维择地。原生与放大的结构边缘强度差 61–81% —— 这是可以验收的客观差距，不是感觉。

文字不加底板。第一版给每个字加半透明垫，分数是达标了，但字从「长在画面里」变成「贴在画面上」， 于是全部撤掉。正解是参考片本来就在用的两条：明度反极（落字处亮就下黑字、暗就下白字）与 择地而居（在允许的窗口里扫位置，挑对比度最高的一条）。

一个被反复修正的教训。低清版与 8K 版必须是同一幅画。最初有三处会偷偷换内容 —— 放大倍率过高就自动换素材、噪声网格按当前分辨率生成、择地步长按渲染像素计。全部改成在设计尺度上算之后， 两批之间的最大偏差降到 6px（画布的 0.6%）。

层序 · 参考片拆解出的搭建顺序

  1. 成片定帧　先给结果，再清空重来
  2. 波纹场 + 人物剪影　先定「能量场」与主体位置
  3. 同心细线 + 网格 + 波形线　灰底，照片尚未进场
  4. 城市照片淡入　压暗去色；波纹改淡紫水彩 + 白描边
  5. 紫色块 / 飞鸟 / 贴纸框 / 情绪小字 / 轨道弧　逐样加入
  6. 人物　剪影 → 线稿 → 局部 → 全彩（本系列最终删除）
  7. 文字层　重复带 / 竖排句 / 主标题 / 底部带
  8. 后期层　颗粒 / 扫描线 / 暗角，统一施加
02 / HUMAN INPUT

人类介入的程度

这一组的介入密度是三个系列里最高的 —— 因为它本来就不是「许愿」，而是写代码。 人写下的是几何、色轴、层序，以及每一个字落在哪里。

概念与文案CONCEPT & COPY
5 / 5

系列定名《千禧迷思》，六帧的锚点 / 分界带 / 竖排句 / 情绪表 / 底部带 / 印章一一咬合， 全部逐字重写。基调还被明确校准过一次：是迷思不是丧，收尾不能写成认命，问题要悬著、人不颓。

代码与参数CODE
5 / 5

渲染器逐层手写：环数、手绘抖动、水彩浓度、飞鸟数、贴纸编号、各段文字的择地窗口， 全部是代码里的具体数字。改一个参数，六帧一起变 —— 这是「画」的层级，不是「调」的层级。

素材与数据MATERIALS
3 / 5

素材库照片（去色、提对比、压暗、按放大倍率补糊）、字体 cmap 比对。素材本身是拿来的， 不是生成的 —— 这也是它能把「照片感」做对的原因。

筛选与迭代CURATION
5 / 5

三套验收同时跑：影调与配色指标（V / S / purple / edge 对照参考值）、字体可见性审计 （探针模式只画背景，差异像素即墨迹，算 WCAG 对比度）、8K 与低清一致性验收。每一轮只改一处主因。

像素级后期RETOUCH
0 / 5

原生渲染直出。不存在「导出后再修」这一步 —— 修图的活全部被前移到了渲染器里， 以参数与算法的形式存在。

介入度：极高。这一组更接近「用代码画画」，而不是「向模型许愿」。 它同时也是唯一一个完全不含扩散模型的系列 —— 没有任何像素是 AI 画的，AI 参与的是渲染器的代码与文案。
