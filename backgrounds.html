东方纯背景

Touhou Backgrounds  ·  Palette-Mapped Compositing

素材库照片、一条从原封面里量出来的色轴、一个程序化的光源 —— 五个系列、百余张无人无字的纯背景。 它们的任务不是被观看，而是被叠上内容：人物、标题、印章，都在这一层之上。

01 / PIPELINE

生成方式

五个系列共用一套底座：素材清洗 → 加权混底 → 色轴映射 → 光源 → 地平线 → 点缀 → 暗角颗粒。 差别只在「素材配比、色轴来源、构图母题」三件事上 —— 每景只换这三样，其余语法不变。

渲染
Pillow + NumPy · 逐像素浮点合成，无模型推理
尺寸
1000 × 1000 / 1400 × 1400 · 排布系列 8000 × 8000 原生
素材
素材库照片 · 依 th06–th13 游戏线分目录，含 380px 级小图
色轴来源
三种 · kmeans 主色相 / 封面调色板重铸 / 手工指定
去水印
径向 inpaint · 素材商标一律抹掉
放大策略
按倍率补糊 · 超过 2.6 倍自动换大图，避免 JPEG 方块被放大
扩散模型
无
后期
无 · 暗角与颗粒在管线内施加，不是导出后加的

色轴怎么来。「原封面背景 54 张」是为特征库里每一张原封面生成一张同色轴的纯拼接背景 —— 从原图做 kmeans 取主色，再按统计亮度校准，因此它与原封面共享同一个色相家族，但不借用原图任何像素。 「二十幻想原画」走得更远一步：取原封面色板的主色相，用圆均值避开色相绕回错误，再重铸成一族由暗到亮的渐变，尾端微微偏冷。

一景一策。「二十新景」沿用被认可的那套配方语法（素材混底 + pastel 色轴 + 光源 + 花瓣光斑 + 暗角颗粒）， 但每一景都在 SCENES 列表里单独写一行：哪两三张素材、什么权重、什么模糊半径、光源落在哪、要不要地平线、 几片花瓣、暗角多深。张张成立且互不相同，靠的是这份手工清单，不是随机。

素材的坑。素材源图最大只有 380px，在一条 5312 宽的带里要放大 20 倍，JPEG 的 8×8 方块会变成 157px 的方格。 藏网格不能靠抹 —— 全图高斯会把结构砍掉一半而方格只降 6%。真正有效的是只平滑块边界那条线（±1px，内部一个像素不碰）， 方格振幅比 1.125 → 0.931，还保住 89% 结构。

一个必须说清楚的区别。这个系列不含任何扩散模型输出。素材是拿来的照片，色轴是量出来的， 其余全部是程序化绘制 —— 它更接近「布景」而不是「画」：无人、无字，只提供质感与光。

共用底座 · 合成顺序

  1. 素材清洗　裁切、去水印、按倍率补糊
  2. 加权混底　2–3 张素材按权重叠成灰阶底
  3. 色轴映射　灰阶 → ramp，暗部到亮部整族替换
  4. 光源　径向遮罩提亮，带强度与半径
  5. 地平线 / 水面　第二素材按 y 渐变压入
  6. 点缀　花瓣 / 光斑 / 星点 / 光束 / 枝条
  7. 收尾　暗角、颗粒、对比曲线
02 / HUMAN INPUT

人类介入的程度

比拼贴画低一档：那边的每个字都是手写进去的位置，这边的人的判断集中在「为这一景挑哪几张素材、配哪条色轴」。

概念与选题CONCEPT
4 / 5

五个系列的方向由人定：原作向（色轴取自真实封面）、梦幻系（统一配方语法）、贺图十色（同管线换色轴）。 母题清单（莲池、富士、星屑、竹苔、藤花…）也是手写的。

提示词与参数PARAMS
4 / 5

SCENES 一景一策：素材配比、色轴 key、光源位置与强度、地平线高度、花瓣数与颜色、暗角深度， 逐景手写在脚本里。没有「一组参数打天下」这种事。

素材与数据MATERIALS
4 / 5

素材库的挑选、清洗、去水印、分辨率兜底全在人这边。色轴数据来自 54 张真实封面的 cover_features.json，是量出来的，不是编的。

筛选与迭代CURATION
3 / 5

以总览对照挑图为主，量化程度低于前两个系列 —— 这一组的验收更接近「一眼看上去对不对」， 没有 p50 / edgeN 那种硬指标。

像素级后期RETOUCH
0 / 5

无。暗角、颗粒、对比曲线都在管线里，作为参数存在；导出后不碰。

介入度：中高。单张的「手感」由配方保证，人的工作在于为每一景挑对素材与色轴 —— 决定它像哪一张专辑、哪一个季节、哪一种光。
